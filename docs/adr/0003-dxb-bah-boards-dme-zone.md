# ADR-0003. Табло Дубая и Бахрейна; DME — зона, стойки и выход из статуса

Статус: **ПРИНЯТО** 14.10.2026 МСК (владелец). Код в `main`: 08abda5, 9a34ff1 (DME), a049104,
2610736, a3b981e (DXB, BAH). Отчёт: [docs/agent_reports/AUDIT-DXB-CPT-BAH/REPORT.md](../agent_reports/AUDIT-DXB-CPT-BAH/REPORT.md).

## Контекст

- Рейсы через Дубай, Кейптаун и Бахрейн шли только через AirLabs (ближайший рейс по номеру).
- DME выдавал «Зону вылета E» за терминал (у Домодедово терминал один) и не показывал стойки,
  выход и посадку, хотя они есть в бегущей строке статуса табло.

## Решение

- **DXB** (`DxbSource`): статический JSON всего аэропорта, вчера/сегодня/завтра. Времена с «Z» —
  на деле местные +04:00. Файл качается один раз на всех (`http.SharedFetch`, 60 с), без scrape.do.
- **BAH** (`BahSource`): POST API сайта на дату, сегодня/завтра, +03:00. «Факт» позже текущего
  момента (API так отдаёт завтрашние рейсы) не принимаем. Статусы — по смыслу.
- Опрос подписки закрепляется за записью источника по `key`: у DXB на одну дату бывает две записи номера.
- **DME**: «Зона вылета» → поле `zone` («🏢 Зона вылета E»; E — международные, D — внутренние);
  из бегущей строки — стойки, время регистрации, выход, начало посадки; пропавший с бегущей строки
  выход не стирается (только DME).
- **CPT**: без своего источника — AirLabs.

## Что отвергли

- Отключить проверку времени у BAH «как есть» — ложные «вылетел/прилетел» снимали бы подписку.
- Тянуть файл DXB через scrape.do — 3,7 МБ платного трафика на каждую загрузку.
- Залипание выхода для всех источников — скрыло бы реальное снятие выхода у SVO/LED/VKO.

## Дополнение — ПРИНЯТО 14.10.2026 МСК (владелец)

Код в `main`: d17d640, 31ad4c6.
- **DXB:** факт вылета — взлёт (`actualTakeOffTime`). Пока самолёт рулит (статус Departed, взлёта
  ещё нет), факт — уход со стоянки: иначе после взлёта пришёл бы повторный пуш.
- **BAH:** статусы переводятся по ключевым словам; «свершилось» (вылет/прилёт, факт) — только если
  статус начинается с Departed/Airborne/Landed/Arrived («Delayed Departure» — не вылет).
- **CPT:** форму ACSA не подключаем — отдаёт меньше AirLabs (без даты, выхода, терминала), постбэк
  SharePoint хрупкий и падал по таймауту. Стойки и посадка DXB — только у авиакомпании, не делаем.
