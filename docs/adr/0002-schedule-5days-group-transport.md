# ADR-0002. Подписка на 5 дней, бот в группе, транспорт табло и расписания

Статус: **ПРИНЯТО** 14.10.2026 МСК (владелец). Код в `main`: df48a71 (5 дней + группа),
8ffee7d (Пулково, параллельный поиск, кэш, DK-прокси, «Гейти»), 556e4a9 (время без офсета, изоляция опроса).
Отчёт: [docs/agent_reports/schedule-5days-group/REPORT.md](../agent_reports/schedule-5days-group/REPORT.md).

## Контекст

- Табло держат только вчера/сегодня/завтра — подписаться на рейс через 3–5 дней было нельзя,
  рейс вне наших табло (EK770 DXB→CPT) давал одну дату из AirLabs.
- Бота хотят в группе Telegram, команды — только от владельца.
- Поиск шёл ~130 с: Пулково с 12.10.2026 отдаёт сертификат без промежуточного, LED уходил в scrape.do.
- RapidAPI отвечает 451 сети сервера бота (AS215540 — «embargoed»).

## Решение

- **Даты на сегодня…+5** — AeroDataBox (RapidAPI) по номеру, только в поиске (`registry.search`);
  табло главнее на своей дате. Снимок расписания — только для карточки при подписке, в опрос и
  диффер не идёт. Рейс в SVO/DME/VKO/LED — табло прилёта и дата прилёта. Подписка вне табло не
  опрашивается до 00:00 МСК накануне даты. Квота — ADR-0001.
- **Группа:** `/track <номер>` (в группе бот видит только команды), подписка и пуши — в чат подписки;
  голый номер — только в личке. `OWNER_IDS` — чьи сообщения и кнопки бот принимает.
- **TLS табло:** certifi + `flight_bot/certs/*.pem` (недостающие промежуточные), проверку не отключаем.
- **Поиск:** табло параллельно, лимит 15 с на табло; AirLabs — только при пустых табло.
  Ответ источника кэшируется на 60 с с объединением одновременных запросов.
- **Выход для AeroDataBox** — SOCKS-туннель до DK-хоста (`deploy/dk-proxy.service`, `SCHEDULE_PROXY_URL`).

## Что отвергли

- Подписка «вслепую» без проверки номера — выбрано расписание из API (решение владельца).
- Yandex Расписания — нет поиска по номеру, только расписание станции; не покрывает DXB.
- Будущие даты из AirLabs — в бесплатном ключе нет.
- Отключить проверку TLS для Пулково — небезопасно; достроили цепочку.
- Переезд бота на webdock или прямой ключ AeroDataBox ($19/мес) — туннель дешевле и обратим.
