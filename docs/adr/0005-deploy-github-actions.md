# ADR-0005. Выкатка из GitHub Actions по SSH

Статус: **ПРИНЯТО** 14.10.2026 МСК (владелец). Код в `main`: 99e504b (PR #3). Первый запуск
`deploy` 14.10.2026 16:16 МСК (13:16 UTC) — зелёный, «уже выкачено: 0ade430».

## Контекст

- Выкатка ручная: `cd /opt/flight-bot && git pull && sudo systemctl restart flight-bot` на riga.
  Проверки после рестарта и отката нет; зависимости обновляются вручную, если вспомнить.
- Репозиторий публичный, лог Actions тоже публичный. На сервере рядом с кодом — `.env`
  с токеном бота и ключами AirLabs, scrape.do, AeroDataBox.

## Решение

- Job `deploy` в `tests.yml`: только пуш в `main`, только после зелёного `pytest`
  (`needs`), environment `production`, `concurrency: deploy` — выкатки идут по одной.
- GitHub-hosted runner ходит на сервер по SSH. Ключ в `authorized_keys` с
  `command="/opt/flight-bot/deploy/deploy.sh",restrict`: shell, проброс портов и агент
  недоступны, строка клиента — только аргумент скрипта. Хост-ключ сервера закреплён
  (`DEPLOY_KNOWN_HOSTS`). Ключ, адрес и порт — в GitHub Secrets.
- `deploy/deploy.sh`: принимает только полный SHA; коммит должен быть в `origin/main`;
  правки отслеживаемых файлов на сервере останавливают выкатку; запоздавший запуск со
  старым коммитом — без действий. Fast-forward, `pip install` только при смене
  `requirements.txt`, `sudo -n systemctl restart flight-bot` (sudoers — только эта команда).
- Smoke: 30 с сервис `active` и PID не меняется (при падении `Restart=on-failure` через
  10 с сменил бы PID). Не прошёл — `git reset --hard` на прежний коммит, рестарт, job красный.
- В лог Actions — только SHA и состояния; журнал бота не печатаем.

## Что отвергли

- **Self-hosted runner на riga.** Не нужен открытый SSH, но в публичном репозитории чужой
  PR может запустить job на сервере с `.env`; запрет для форков — настройка, которую легко
  сбить. Остаётся запасным, если SSH на riga из интернета закрыт: отдельный пользователь
  без доступа к `.env`, только `push` в `main`.
- **`probe` в smoke.** Ходит во все источники и тратит квоты AirLabs и AeroDataBox
  (ADR-0001); остаётся ручной проверкой.
- **Поиск Traceback в журнале.** Поллер логирует и переживает ошибки отдельных подписок,
  трейсбек не значит, что бот лежит; к тому же журнал нельзя выводить в публичный лог.
