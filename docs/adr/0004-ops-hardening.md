# ADR-0004. Эксплуатация: секреты в логах, мониторинг, МСК в карточке, бэкап, CI

Статус: **ПРИНЯТО** 14.10.2026 МСК (владелец). Код в `main`: ff8f242, 91e7b6e, 96e1748, b3cb9fb
(логи и мониторинг), 2c2615f, 22b8533 (МСК), ebfcb18 (бэкап), 4b04945 (CI), 4faeeb6 (сертификаты).

## Контекст

- httpx на INFO писал каждый запрос с полным URL: ключи AirLabs (`api_key`) и scrape.do (`token`)
  лежали в journalctl и syslog сервера (89 и 8 строк).
- Пулково молчало почти двое суток (12–13.10), сбой никто не заметил.
- Время немосковских аэропортов показывалось без подписи пояса.
- Бэкап базы — только вручную перед выкатом; CI не было.

## Решение

- **Логи:** логгер `httpx` → WARNING; `http.describe(exc)` (класс, код HTTP, хост — без URL) в
  уведомлениях и `log.warning`; форматтер лога вырезает `api_key/token/key=…`, токен бота в пути и
  логин:пароль прокси из любой строки и трейсбека. Журнал systemd на riga очищен, в syslog значения
  ключей заменены на `[скрыто]`. Ключи **не перевыпускались** — решение владельца.
- **Мониторинг** (`health.py`): 6 ошибок источника подряд и ≥30 мин — «⚠️» владельцам из
  `OWNER_IDS` в личку, после первого успеха — «✅»; пустой ответ — не сбой.
- **Время:** немосковский аэропорт — местное и «(HH:MM МСК)»; без офсета — как есть. AirLabs без
  UTC-пары больше не подставляет +00:00.
- **Бэкап:** `flight_bot/backup.py` + `deploy/flight-bot-backup.timer`, 04:00 МСК, 14 дней,
  `~/flight-bot-backup/daily`.
- **CI:** GitHub Actions, pytest на Python 3.12 (как на сервере); для публичного репо бесплатно.
- **Хук git-gates:** публичные сертификаты из `.claude/public-certs` коммитятся; прочие `.pem` — отказ.
- **Процесс:** параллельные сессии — каждая в своём worktree.

## Что отвергли

- Ранний ответ поиска по первому найденному табло — выигрыша почти нет (рейс вне Москвы ждёт
  табло выше по приоритету, медленнее всех DME ~6,6 с), код сложнее.
- Исключение для всего `certs/` в хуке — там может лежать закрытый ключ.
- Только МСК или только местное время — пассажиру в чужом аэропорту нужно местное, остальным — МСК.

## Открыто

- Бесплатный ключ AirLabs действует до 05.11.2026 03:00 МСК (1000 запросов/мес) — продлить заранее.
