# Время без офсета роняет дифф и круг опроса

Дата: 14.10.2026 (МСК). Ветка: `claude/priceless-elion-126f70`, без push.
Статус: **РЕАЛИЗОВАНО, НО НЕ ПРИНЯТО** — независимая верификация и приёмка не проводились.

## Исходная проблема

- `diff._shift_min`: вычитание времени без офсета и с офсетом → `TypeError: can't subtract
  offset-naive and offset-aware datetimes` (воспроизведено ревьюером).
- `poller.poll_once`: `diff_snapshots` в цикле без `try/except` — исключение обрывает круг,
  остальные подписки не получают `set_next`; у упавшей `set_last` уже перезаписан, изменение
  теряется молча.

## Аудит

### Какие источники отдают время без офсета (фикстуры `tests/fixtures`)

Метод: весь тест-сьют (99 тестов) прогнан с перехватом `Leg`/`Checkin`/`Boarding`, собраны
все ISO-времена, построенные модулями `flight_bot/sources/*`.

| Источник | С офсетом | Без офсета |

| svo | 114 | 0 |
| vko | 126 | 0 |

Подозрение на DME не подтвердилось: `_at` делает `fromisoformat(row["plan"]).replace(hour=…)`,
`replace` сохраняет пояс, а `row["plan"]` приходит из `_when` с `tzinfo=MSK` (так с коммита

- `last_json` в БД хранит строки как их отдал источник — смесь при сравнении со свежим снимком.

### DME: пояс времени второй стороны в Detailed

Detailed отдаёт время без пояса: `Время отправления | (Куляб) | 11:35`, `_at` приклеивает `+03:00`.
Проверено по опубликованному расписанию U6 2770 Куляб→Домодедово (rasp.yandex.ru): вылет
13:40 местного (Куляб, UTC+5) = 11:40 МСК, в пути 4 ч 35 мин, прилёт 16:15. DME показывает 11:35 —
это **московское** время, `+03:00` верен. Изменений в `dme.py` нет. Расхождение 5 мин — разница
расписания на дату, не пояс (местное дало бы 6 ч 40 мин в пути).

## Решение

Указание владельца: время без офсета не считать МСК — у вылета не из Москвы оно местное.

1. **diff** (`2df2397`): время без офсета берёт пояс своей пары — это то же плечо, тот же
   аэропорт. Тест на Новосибирск (+07:00) различает подходы: ожидается +50 мин, при «МСК по
   умолчанию» было бы −190.
2. **poller** (`3ef7832`):
   - обработка подписки вынесена в `_handle`, обёрнута в `try/except` с `log.exception`;
     упавшая получает `set_next(epoch + near)`, остальные — пуш и свой интервал;
   - `set_last` перенесён после отправки (согласовано): упавшее изменение повторится.
     Минус: если упадёт `send`, возможен повторный пуш;
   - `interval_for`: у вылета без офсета пояс не угадываем — частый опрос `near`.
3. **render** (`e5a4016`): если хоть одно из времён отсчёта без офсета — отсчёт `""`.
   Пропуск отдельного времени отвергнут: до вылета показалось бы «В пути, до посадки».

Отвергнуто: «без офсета = МСК» в diff/poller — неверно для вылетов не из Москвы.
